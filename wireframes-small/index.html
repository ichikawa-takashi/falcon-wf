春日井中央 不動産サイト ワイヤーフレーム（B案：小規模版）

6ページ＋プライバシーポリシー。手元の資料と、ホームページとして最低限必要な情報だけで作れる構成です。10ページ版は A案の一覧 にあります。

#ページ主な内容
01トップMV → 種別から探す → 新着物件 → 相続・空き家のお悩み → 4つの売り方 → はじめての方へ（流れ） → お知らせ → CTA → 対応エリア・店舗
02物件一覧種別タブ、物件カード、ページ送り、希望条件はお問い合わせへ
03物件詳細価格・写真・おすすめポイント・物件概要・地図・問い合わせ・同じ種別の物件
04売却・買取4つの売り方（診断フロー図）、空き家・相続、売却の流れ10ステップ、媒介契約3種、費用
05購入ガイド購入の流れ13ステップ、資金計画・諸費用、金利タイプ、返済例、必要書類、契約から決済まで
06会社案内・お問い合わせ会社概要、アクセス、共通フォーム1本
＋プライバシーポリシー定型文

神領不動産（ベンチマーク）との対応

トップの並びは神領不動産の「お悩み → 売却メニュー → 売却の秘訣 → 最新情報 → CTA → 対応エリア → 会社情報」を守り、そのうえに必須の物件導線（種別・新着物件）を加えています。コンセプトや素材が必要な「選ばれる理由」「代表紹介」「動画」「解決事例」の枠は外しました。

10ページ版から外したもの（後から追加できる）

外したもの理由追加するときの場所
選ばれる理由・代表あいさつ会社のコンセプト・強みが未定トップの「4つの売り方」の前／会社案内の上部
スタッフ紹介・採用情報写真・プロフィールが必要会社案内に追加
実績・お客様の声（独立ページ）件数・アンケートの収集が必要当面はトップの「お知らせ」（契約済・買い取りました）で代用
お知らせ・コラム（一覧ページ）更新の体制が未定記事が増えたら一覧ページを追加
動画手元の動画特集はハウスドゥ本部のもので、独立後は使えない可能性が高い自社のYouTubeができたらトップに追加
空き家・相続（独立ページ）解決事例・提携先の情報が必要売却ページ内のセクションから独立させる
売却タイプ診断（クリック式）開発工数の削減静的な図で掲載済み。必要ならクリック式に変更
売却のよくある質問回答の作成が必要売却ページの最後

クライアントから最低限いただくもの

  • 屋号・ロゴ（ハウスドゥの名称を使えるか）
  • 宅地建物取引業の免許番号、代表者名
  • フリーダイヤルを独立後も使えるか、LINE公式アカウントの有無
  • 買取保証・リースバックを独立後も扱うか
  • 店舗外観の写真（1〜2枚）、駐車場の台数・行き方
  • 物件データ（写真・概要）の登録方法の確認
